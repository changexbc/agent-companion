# Agent Companion · Agent 小伴

独立、轻量的桌面 Agent 会话助手：查看任务状态、接收提问提醒，并跳转回原会话。

## 当前状态

本仓库已初始化，目前仅包含项目说明与迁移边界，尚未迁入应用代码，暂不可构建或运行。

## 产品范围

- 桌面悬浮栏、头像与会话详情。
- 会话监控、状态归一化、提问提醒与原会话跳转。
- 托盘、设置及后台服务生命周期。
- 初期由本仓库维护监控核心与运行服务。

3D 办公室作为独立的可选应用，通过明确的数据接口读取监控状态。本项目不依赖办公室源码、本地路径、Three.js、场景模型或光照资源。

## 迁移原则

1. 保留已有交互和真实监控能力；迁移与重新设计分开进行。
2. 先梳理必要依赖，再迁入桌面 UI、原生壳、监控核心、资源和对应测试。
3. 新项目可以独立安装依赖、构建和运行。
4. 明确 Hook、配置和后台服务的归属，防止多个宿主重复监听、重复提醒或相互终止服务。
5. 新项目验证完成之前，保留来源项目的原实现与未提交工作。
6. 为现有嵌入宿主保留明确的兼容或迁移路径。

## 首阶段验收

- 不包含 3D 资源仍可独立构建、安装和启动。
