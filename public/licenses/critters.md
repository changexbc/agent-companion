# DiceBear Critters

Artwork: DiceBear, Critters 10.6.0.
Source: https://www.dicebear.com/styles/critters/
Definition: https://cdn.hopjs.net/npm/@dicebear/styles@10.6.0/dist/critters.min.json
License: CC0 1.0 https://creativecommons.org/publicdomain/zero/1.0/

`src/desktop/critters-data.json` contains ten locally generated portraits and
expression fragments from this definition. Agent Companion adds pointer gaze,
status expressions and motion. No remote image or avatar API is used at runtime.
